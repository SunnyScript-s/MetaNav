# Voice navigation for Meta glasses

Two versions of the same idea: put on your glasses, say where you want to go, and get
turn-by-turn directions in your ears.

**Use the iPhone version:** [`meta-nav-ios/`](meta-nav-ios/README.md)

That is the one that runs on an iPhone. It is written, and its logic is tested, but it still
has to be built once in Xcode on a Mac. The README walks through it in plain language.

`meta-nav/` is the older Android version. It is finished and tested, but it cannot be
installed on an iPhone.
